# 🤖 Gerador de Imagens por IA

Este é um projeto prático desenvolvido para explorar o potencial da Inteligência Artificial na criação visual. A aplicação permite que usuários insiram descrições em texto (prompts) e gerem imagens inéditas de alta qualidade de forma automatizada.

---

## 🚀 Tecnologias e Ferramentas Utilizadas

O projeto foi construído combinando lógica de programação robusta com ferramentas modernas de desenvolvimento assistido por IA:

* **Python:** Utilizado no desenvolvimento da lógica de backend, manipulação de dados e integração de APIs.
* **JavaScript / HTML5 / CSS3:** Implementação de uma interface web dinâmica, responsiva e focada na experiência do usuário.
* **Claude Design:** Utilizado na fase de prototipagem para criar uma interface do usuário (UI) moderna, limpa e com boas práticas de acessibilidade.
* **Claude Code:** Integrado ao fluxo de trabalho via terminal Linux para acelerar o processo de refatoração do código, depuração de erros e otimização de performance.
* **Git & GitHub:** Controle de versão e documentação contínua do projeto.

---

## 💡 Recursos em Destaque

* **Consumo de APIs de IA:** Conexão integrada para envio de prompts e recebimento de assets visuais em tempo real.
* **Desenvolvimento Ágil e Assistido:** Demonstração prática de como utilizar assistentes de IA para aumentar a produtividade e a qualidade do código entregue.
* **Ambiente Linux Nativo:** Todo o fluxo de desenvolvimento, testes de scripts e automações foram executados em ambiente Linux.
